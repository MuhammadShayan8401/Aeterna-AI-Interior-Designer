# Security Policy

## Supported Versions

Aeterna AI Interior Designer is an actively developed project. Security fixes are prioritized for the latest maintained version.

| Version | Supported |
| ------- | --------- |
| Latest release | Yes |
| Older releases | No guarantee of security updates |

If you discover a vulnerability in an older version, please report it so that its impact can be assessed.

## Reporting a Vulnerability

If you discover a potential security vulnerability, please report it responsibly.

**How to report:**
- Use [GitHub's private vulnerability reporting](https://github.com/MuhammadShayan8401/Aeterna-AI-Interior-Designer/security/advisories/new) if private vulnerability reporting is enabled for this repository.
- If private reporting is unavailable, contact the repository maintainer privately through GitHub before disclosing the issue publicly.

**Please include:**
- A clear description of the vulnerability.
- Steps to reproduce the issue.
- The potential impact.
- Relevant logs, screenshots, or proof-of-concept details, where safe to share.

**What to expect:**
- Your report will be reviewed as soon as reasonably possible.
- You may be contacted for additional information or clarification.
- If the vulnerability is confirmed, appropriate remediation will be considered.
- If the report is declined, an explanation will be provided where reasonably possible.

Please avoid publicly disclosing vulnerabilities before the maintainer has had a reasonable opportunity to investigate them.

Thank you for helping keep Aeterna AI Interior Designer secure.
